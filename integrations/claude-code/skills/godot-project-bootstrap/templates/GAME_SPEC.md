# GAME_SPEC — <game name>

> What the game is. Changes only when the design changes; the user confirms every change.

## Pitch
One or two sentences: genre, setting, what the player does.

## Pillars
3–5 things the game must get right. Features that serve none of them are out of scope.

## Core loop
What the player does minute to minute, and what brings them back.

## Scope
- **In:** the features the first playable version needs.
- **Out (for now):** ideas explicitly postponed.

## Target
Engine version (Godot 4.x), platforms, input (mouse/keyboard, controller), resolution / 2D or 3D.

## Open questions
Design questions not answered yet. Remove each when it is decided (and record it in DECISIONS.md).
