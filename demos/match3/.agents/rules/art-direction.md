# Art direction - match3 demo
Mood: "candy dusk" - warm dark purple background, glowing candy gems.
Palette (only these + tints/shades):
- background deep : #1b1430
- background mid  : #2b1c4a
- surface cell    : #3a2a5e
- surface hi      : #4b3780
- primary text    : #f4ecff
- accent (score)  : #ffc94d
- danger (no move): #ff5d7a
Gem types (6): #ff5d7a, #ffc94d, #6ee7a8, #5ac8fa, #c08bff, #ff9f5a
Field: 8x8 grid, cell 74px, board ~640px -> fills short side of 1280x720.
UI style: rounded panels (radius 14), title 40, HUD 24, body 16, dark panel + light text.
Effects: subtle - scale pop on spawn (0.18s), flash 120ms on clear, no screen shake.
